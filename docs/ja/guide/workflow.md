# 制作フロー

このリポジトリは、ソフトウェアのビルドというより、クリエイティブ制作物を再確認・引き継ぎしやすくするための構成です。

## 1. コア静止画を生成する

最初に正方形 CD ジャケットと 16:9 MV 背景を作ります。ここで色調、人物、自動販売機の祭壇感、冷たい高架下の空気感を固定します。

## 2. リリース用タイポグラフィを追加する

ベース画像が安定してからタイトル入り版を作成します。アートワークを保ちつつ、次の文字列を読みやすく維持します。

- `VENDING MACHINE STIGMATA`
- `AYANO YUKIMURA`
- `アヤノ ユキムラ`

## 3. モーションテストを生成する

16:9 タイトル画像を開始フレームと終了フレームにして、ループ映像を生成します。カメラは固定し、霧、布、髪、LED、反射、人物の微細な動きだけを動かします。

## 4. 書き出しと保管

完成レンダーは `output/video`、生成元クリップは `video`、高解像度画像は `output/imagegen` に保管します。

## 5. ドキュメントを公開する

公開前に docs をビルドします。

```powershell
npm --prefix docs install
npm --prefix docs run docs:build
```

GitHub Pages ワークフローは `docs` をビルドし、`docs/.vitepress/dist` をアップロードします。
