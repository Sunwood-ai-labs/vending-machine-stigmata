# プロンプト記録

完全なプロンプト履歴は [GENERATED_ASSETS_AND_PROMPTS.md](https://github.com/Sunwood-ai-labs/vending-machine-stigmata/blob/main/GENERATED_ASSETS_AND_PROMPTS.md) に保存しています。画像生成、タイトル入り編集、15 秒ループ映像用プロンプトを追えるようにしています。

## プロンプトの系統

| 系統 | 用途 |
| --- | --- |
| ベース CD ジャケット | タイポグラフィなしの正方形アルバムカバーを作成。 |
| ベース MV ループ画像 | モーションやオーバーレイに使いやすいワイド背景を作成。 |
| リテール CD ジャケット編集 | 既存イラストを保ち、タイトルとアーティスト名を追加。 |
| MV タイトル画像編集 | 16:9 構図を保ち、タイトル画面として整える。 |
| 15 秒ループ最終プロンプト | 固定カメラ、シームレスな動き、文字保持、visualizer なしの映像生成を指定。 |

## 維持する要素

- タイトル `VENDING MACHINE STIGMATA` を正確に保つ。
- `AYANO YUKIMURA` と `アヤノ ユキムラ` をタイトル画像編集時に崩さない。
- 自動販売機を祭壇のように扱う構図、氷のようなアーティスト表現、暗い高架下、シアン/赤の光、非流血の stigmata 風発光を維持する。
- 波形、イコライザー、字幕、偽ロゴ、バーコード、追加人物は入れない。
