# Rights and Publishing

The repository uses an all-rights-reserved license. Viewing and evaluating the materials is allowed, but reuse, redistribution, derivative works, commercial use, public performance, or machine-learning use requires explicit permission.

## Distribution Notes

- Keep source references out of the repository unless they are cleared for publication.
- Use Git LFS for media files before pushing to GitHub.
- Confirm that final files are present with `git lfs pull` before creating a release package.
- Do not treat the generated prompt archive as an open license for the artwork or music.

## GitHub Pages

The Pages site is intended to be built from GitHub Actions with the VitePress base path `/vending-machine-stigmata/`.

If the Pages workflow fails because Pages is not enabled, enable Pages for GitHub Actions in repository settings or via the GitHub API, then rerun the workflow.
